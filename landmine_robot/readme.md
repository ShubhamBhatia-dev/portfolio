Developed an autonomous mobile robot using ESP32, ultrasonic/IR sensors, MPU6050, wheel encoders, and dual-motor
control for real-time navigation and obstacle avoidance.
– Implemented encoder-based (x, y) position tracking and gyroscope-based heading estimation, with sensor fusion for corridor
centering, obstacle detection, clearance estimation, and adaptive turning.
– Built a WiFi-enabled Flask interface for real-time telemetry and remote START/STOP control, transmitting sensor, position,
orientation, and encoder data.
